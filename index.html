Projects

Selected work, starting with the project I am most proud of.

Paylane Payment-Support Agent

Take-home project

A Python customer-support agent using an OpenAI-compatible chat endpoint and four tools, with an optional FastAPI wrapper (/health, /chat). Critical decisions (identity verification, lockout after 3 failed attempts, refund eligibility, human escalation and card-data protection) are enforced by deterministic server-side policy checks rather than left to the LLM.

  • 75 deterministic tests, all passing.
  • A live LLM evaluation of 12 scenarios, all passing, with JSON transcripts. It covers aggressive duplicate refunds, fraud claims, legal threats and third-party access attempts.
  • Documentation of a failure the evaluation missed, how it was found and how it was fixed, plus design notes, edge cases and an AI-assistance disclosure.
